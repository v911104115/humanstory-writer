# HumanStory Writer

**面向小红书与商业内容创作的自然叙事 AI Skill。**

让文章更接近真实从业者的工作观察，减少机械断行、套路煽情、强行升华与生硬广告植入。

## 适用场景
- 搬家、租房、留学、医美、法律咨询等服务行业
- 小红书账号冷启动、故事型内容营销
- 已有文章的自然化改写与内容自检

## 使用方法
将 [SKILL.md](./SKILL.md) 提供给支持自定义指令或 Skills 的 AI 工具，要求按照其中的规则写作或改写。

**示例指令：**
> 按照 HumanStory Writer 的规范，为韩国搬家服务账号创作一篇小红书故事。使用我提供的真实搬家案例，保留具体工作细节，避免一句一段、套路化煽情和硬广。若素材不足，请先提出需要补充的关键事实。

## 核心原则
1. 从真实事件与职业观察出发，不伪造客户经历。
2. 让业务通过专业工作细节自然呈现。
3. 使用不规则但易读的自然段落，不刻意制造“AI 感”或“反 AI 感”。
4. 不强行制造情绪反转、金句和结论。
5. 注意客户隐私、事实核实及适用的广告披露要求。

完整规范见 [SKILL.md](./SKILL.md)。
